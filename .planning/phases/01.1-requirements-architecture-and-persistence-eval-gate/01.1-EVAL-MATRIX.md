# Phase 01.1 Eval Matrix

Bu matrix, sekiz yuksek riskli davranis icin owner fazi, validation modu, canonical source ve beklenen failure signal bilgisini dondurur.

## Validation Modes

- `automated`: unit/widget/integration test ile kapanan davranis
- `manual`: insanin kaynak dokuman ile birebir karsilastirarak kapattigi deger veya sunum davranisi
- `mixed`: otomatik davranis testi + manuel sabit dogrulamasi birlikte gerekir

## Manual Gate Contract

Downstream execution asagidaki kurala uymadan ilgili item'i complete sayamaz:

1. Otomatik coverage tamamlanir ve gecen testler raporlanir.
2. Eger matrix satiri `manual` veya `mixed` ise agent sohbette acikca `MANUAL GATE` diye bildirir.
3. Agent, kullaniciya tam kontrol listesini ve dogrulanacak canonical source'u belirtir.
4. Kullanici "dogruladim" demeden ilgili task/plan kapanmaz.

Bu kontrat ozellikle su satirlar icin zorunludur:
- Frekans bazli playable-grid guarantee / fallback
- Joker price / effect sync
- Aggregate score metrics / newest-first history
- Persistence / background resume
