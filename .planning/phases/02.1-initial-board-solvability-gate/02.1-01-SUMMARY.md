# Phase 02.1-01 Summary — Initial Board Solvability Gate

**Completed:** 2026-04-18
**Status:** ✅ Done

## Objective

Guarantee that the first board shown to the player is always
playable before core gameplay continues. Pull the highest-risk
dead-board failure forward so a newly started game never opens
on a useless grid.

## Changes Made

### New Files

#### `lib/src/core/gameplay/services/board_analyzer.dart`
- `BoardAnalyzer` class with trie-backed DFS + backtracking
- Builds a compact trie from the dictionary word set
- Walks the board using 8-directional adjacency with no-repeat-cell
- Prefix pruning: branches are cut as soon as the trie has no child
- Short-circuits on first valid word (≥3 chars) found
- Returns `bool` — designed for the yes/no initial-session guard

#### `lib/src/core/gameplay/services/board_recovery.dart`
- `BoardRecovery` class with two-stage recovery
- **Stage 1 — Shuffle:** Fisher-Yates shuffle of existing letters,
  preserving all other session state
- **Stage 2 — Regenerate:** full `BoardGenerator.createSession()`
  with weighted letter frequency rules
- `RecoveryStrategy` enum (`none`, `shuffle`, `regenerate`) exposed
  for diagnostics and testing
- Throws `StateError` if both strategies are exhausted

#### `test/core/board_analyzer_test.dart`
- 14 unit tests covering analyzer and recovery:
  - Valid board detection, dead board detection
  - Prefix pruning, no-cell-reuse, diagonal adjacency
  - Empty board / empty dictionary edge cases
  - Larger board (3×3) support
  - Min word length enforcement
  - Recovery: already playable → unchanged
  - Recovery: shuffle or regeneration on crafted dead board
  - Recovery: shuffle preferred over regeneration
  - Recovery: regeneration fallback
  - Recovery: exhaustion throws StateError

### Modified Files

#### `lib/src/features/game/game_controller.dart`
- Added `DictionaryRepository` and `BoardAnalyzer` as injectable
  constructor parameters (defaults provided)
- `load()` now loads the dictionary, creates the session, then
  runs `BoardRecovery.ensurePlayable()` before assigning `_session`
- Dead board never reaches first render
- `fromSession()` factory updated with new parameters
